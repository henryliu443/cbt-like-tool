## 已知问题 / 坑
1. `MoodInsightsView` 有 `@Query` 宏直接写在 View 里（2 个），Skip 不支持，必须先移到 ViewModel
2. `HistoryViewModel.toggleFavorite()` 和 `SettingsViewModel.clearAllData()` 直接接收 `ModelContext` 参数，需重构为 Repository 模式
3. `SettingsViewModel` 有 `import UIKit` 和 `UINotificationFeedbackGenerator`，需隔离到 `HapticManager`
4. `import Charts`（Swift Charts）Skip 不转译 Android，需要 `#if SKIP` 分支
5. Skip 要求特定的 Package.swift 项目结构，迁移前先开 `feature/skip-migration` 分支
